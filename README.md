# 🏏 Cricket Strategy Intelligence System

## 📌 Description
This project analyzes cricket player performance and provides match strategy suggestions using data analytics.

## 🚀 Features
- Player performance analysis (Spin vs Pace)
- Best batting phase detection
- Best partnership prediction
- Match situation analysis
- Toss decision system
- Match win probability prediction
- Performance graph visualization
- Best Partner Image and Strong Opposite image 
## 🛠️ Technologies Used
- Python
- Pandas
- Streamlit
- Matplotlib

## ▶️ How to Run
1. Install libraries:
   pip install pandas streamlit matplotlib

2. Run app:
   streamlit run app.py

## 📊 Dataset
IPL Ball-by-ball dataset
